Merged duplicates: F-0134

what

The application allows unauthorized access to account details by reading them based on ID without checking the user’s ownership. GET /api/accounts/{id} returns owner-specific fields, even when accessed by non-owner users.

where

    39 |         raise HTTPException(status_code=404, detail="account not found")

impact

exploit

fix

Add an owner check before the object is returned.

+++ b/app/routes/accounts.py

     if row is None:
         raise HTTPException(status_code=404, detail="account not found")
